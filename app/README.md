## 启动

需要 Node.js 24.15 或更新的兼容 LTS 版本。

```powershell
cd E:\立体书\app
npm install
npm run dev
```

- 样品：<http://127.0.0.1:4173/demo>
- 工作室：<http://127.0.0.1:4173/studio>
- 第一次启动自动生成工作室密码，见 `.data/管理员登录.txt`。密码不会写进前端。

生产构建：

```powershell
npm run build
npm start
```

可设置 `PORT`、`DATA_DIR`，首次初始化时可设置 `ADMIN_PASSWORD`。已有数据目录以已存密码为准。启动监听本机 127.0.0.1；公网部署需另配 HTTPS 反向代理和持久数据卷。

## 制作一份作品

1. 登录工作室，新建邀请函。
2. 填姓名、日期、当地时间、时区、地点地址、邀请文字。正式作品需填写有效 HTTPS 地图链接。
3. 填故事及流程，上传最多六张照片，按需要裁剪、旋转和排序。
4. 保存草稿，生成 7 天有效的只读预览，交给新人核对。
5. 在「访问与发布」设置到期日及可选访问码，记录本版已核对，再发布。
6. 发送正式链接，保存分享封面。之后修改仍使用原正式链接。

草稿不会直接改变已发布内容；预览保存独立快照；裁剪生成新资产，不改变旧发布版。恢复上一版先载入草稿，核对后再次发布，访问设置保留当前值。

## 素材

`public/assets/` 内有两个生成的透明 PNG 图集和八个 WebP 部件：庄园、花拱、草地、新人、咖啡馆、石桥、相框、仪式亭。使用内置 imagegen 工具生成，生成提示词见 `docs/素材生成记录.md`。工具未向调用参数开放具体模型版本选择，模型版本以图像生成服务实际路由为准。

所有展示素材本地托管。字体使用系统字体；背景音乐为 Kevin MacLeod《Midsummer Sky》（CC BY 4.0），翻页声为 davidbain《Page Turn》（CC0），默认关闭。来源、署名及处理方式见 `docs/音频来源.md`；网页署名弹层应保留。上传照片处理采用 Sharp，剥离 EXIF，仅将派生图发给宾客。

## 检查

```powershell
npm test
npm run build
```

测试包含内容校验、时区日历，以及管理员验证、草稿隔离、不可变预览、照片裁剪、发布、跨作品访问隔离和撤回的接口流程。浏览器验收脚本及截图在 `qa/`。

`.data/` 保存 SQLite 数据、账号及会话，禁止提交。备份时保留整个数据目录及同版代码、素材；正式托管前需验证备份恢复、日志保留与删除流程。
