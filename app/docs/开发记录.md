## 设计取舍

八张已选图决定本次画风与构图，未采用随机站点模板。视觉主体是可操作的纸艺书，系统控件围绕书体布置。现阶段使用 Express 同时承载前端与 API，减少本机运行步骤；后续可将数据层迁移到对象存储及托管数据库。

## 2026-11-04 低机位调整

按用户反馈，将展开状态改为正对新人的低机位。相机高度从 4.6 过渡到 1.75，瞄准点从 (0,0.5,1.2) 过渡到 (0,0.95,1.9)，桌面俯角约从 28° 降到 6°。窄画幅略后移相机；封面和展开状态连续过渡，跳过动画同帧同步更新相机。

验证：TypeScript / Vite 构建通过；浏览器检查开书、跳过动画、第四章、合拢及重新打开。1440×900 与 390×844 截图见 qa/low-camera-20261104/；手机保留 3D Canvas，无网页横向溢出，但圆形底板左右仍被裁切。该轮仅调整机位，先前记录的纸片穿插、底板造型和美术偏差未据此标记解决。浏览器脚本 round-08.mjs 为当次验收记录，其任务空间已完成，不可直接复用原编号。

## 2026-11-04 第一幕整体重绘与放大

- 根据已选参考生成一张完整构图和五张独立部件：庄园、树冠景框、左右树篱、新人、草地小径。保留 PNG 原图、来源及完整提示词，见 docs/第一幕重绘素材记录.md 和 art/garden-v2/。
- 新增 FirstGarden.tsx，将第一幕改为矩形展开书页、可见中缝与多层纸边，五个素材分别用于不同深度的景片或地面。树冠、新人、庄园均保持正面低机位。
- 第一幕展示区桌面从 44vh 调整为 60svh，手机从 40svh 调整为 54svh；压缩标题与正文间的留白，按窄屏调整植物宽度及相机距离。这里是展示区占比，不是全部有效图像像素占比。
- 开合时隐藏非当前章节，避免多个章节的人物重叠。第一幕景片错开起立时间；封面与展开场景分阶段显示。仍是程序化开合效果，不宣称完成了完整物理折纸机关。
- 修正低帧率情况下动画时间推进过慢的问题：使用更合理的实际帧间隔，并由 3D 的实际完成回调关闭动画提示。QA 通过 canvas 的 data-motion=settled 判定稳定状态，避免把固定 UI 定时器当作渲染完成依据。
- 静态备用展示接入同一套完整构图，手机上采用居中裁切，保留人物和庄园。和 3D 版的透视、树冠比例仍有差异。

验证：TypeScript / Vite 生产构建通过；浏览器操作检查四章切换、合拢、打开、邀请正文与备用展示。最终 1440×900、390×844 稳定画面保存在 qa/garden-v2/desktop.png、mobile.png、static.png。390px 下保持 3D，书页两侧可见，无页面横向溢出。投影仍偏硬、纸片轮廓没有完整挤出厚度；美术接受与微信真机性能待用户确认。构建保留原有大体积 3D 分包提示。

本地预览改为隐藏后台 Node 进程，避免当前执行会话结束导致预览关闭；运行日志在 .data/preview-stdout.log、preview-stderr.log。重新构建后仍需重启生产服务才能读取新的 HTML 入口。
