# 第一幕自检与美术对照

日期：2026-11-04。范围：第一幕当前实现、所选八张参考、生成图集与实际网页画面。本次为检查记录，未修改产品代码或替换素材。

**结论：第一幕的主体辨识、基础交互可以保留；美术尚未达到选定参考的表现。优先问题包括开书时的纸片穿插、画布裁切、书体辨识、植物层次及素材画风。**

用户评价“第一幕的效果还行”记录为对当前效果的初步反馈，不等于整套美术或全部验收项通过。

### 2.1 代码核对

- `src/Book.tsx` 的 `Paper` 使用透明平面和 `FrontSide`。当前轮廓主要由图片透明度形成，没有沿植物轮廓建出的纸边厚度，也没有背面印刷材质。底板有厚度不代表纸片有厚度。
- `World` 同时更新所有带 `fold` 标记纸片的 X 轴角度，以及各扇区的 Y 轴角度。它能产生展开动画，但未建立实际折纸机关的连动和避让。
- 第一章实际上有六张景片：拱门、建筑、新人、三张重复花草。数量接近 PRD 的层数目标，但缺少不同功能的空间层，不能按数量判定达到参考效果。
- `Page` 通过扇形 `Shape` 生成底板；相机使用固定位置与 FOV。上述结构与本次圆盘感、窄屏裁切的观察一致。

## 4. 生成素材为什么偏离

当前图集有统一性，但统一在偏暖、细密、复古花艺插画上。原图中的植物已经偏橄榄与米白，进入浅底、强光的 3D 场景后，对比进一步变弱。

素材生成记录里使用了 `pale terracotta`、`cream`、`sage`、`faded dusty-rose`、`delicate`、`intricate` 等描述。这些词组合后容易得到现在的细密、柔和结果；对大面积深绿、树篱轮廓、纸层开窗、真实支撑的约束不足。记录中未见把选定参考作为图片输入的步骤。

四个部件放在同一张图集中生成，能保持大体画风，但难以严格控制每个部件的完整外轮廓、比例、透明留边、纸白边宽度。图集中花拱顶端已贴近画幅，后续分图的安全边距也不足。

本次原图查看中，主体外可见零碎残点；当前渲染的 alphaTest 会过滤部分像素。应对白底、深底的实际导出素材逐个检查，不把查看器的黑色透明底当作素材背景。

## 5. 第一幕下一版制作规格

### 5.1 构图与画风

主场景保留庄园、新人和花园。采用 P01 的建筑水彩与纸张结构、P04 的连续地景、P05 的深绿层次。P08/P12 只借层层开窗的空间方式。不要把八张参考的植物、人物、颜色平均混合。

先制作完整第一幕构图稿，并同时检查桌面与 390px 手机大小。构图达到要求后，再生成独立部件并拆分搭建。

| 层 | 内容 | 目的 |
| --- | --- | --- |
| 书体 | 有书脊和页缝的纸页、底部折叠支撑 | 让人一眼看出是打开的立体书 |
| 地景 | 连续草地、水彩小径，边缘逐渐留白 | 连接零散景片，消除空底板 |
| 远景 | 稀疏远树、天空留白 | 提供场地环境，避免与庄园争夺注意 |
| 主景 | 完整庄园立面，清楚门窗和屋顶 | 场地成为能够辨认的主体 |
| 中景 | 左右不同的树篱与藤蔓 | 形成开口、遮住连接部位 |
| 人物 | 成人比例插画，较概括的衣褶与自然动作 | 与水彩建筑统一，手机大小能辨认 |
| 近景 | 两组独立叶片和少量花朵 | 建立景深，避免重复同一条花带 |

### 5.2 生成与代码分工

- 生成：庄园水彩、人物插画、植物笔触与地景纹理。每张部件有独立文件和足够透明留边，使用选定参考图片约束媒介、色彩和轮廓；不用参考里的原文字、人物或原建筑做直接复制。
- 代码：纸边厚度、背面、折线、支撑、开合顺序、动态投影、相机适配、可替换文字。图片里不烘焙依赖固定视角的投影。
- 先生成一张整体构图稿以验证方向，再做单部件。避免继续用四宫格批量生成作为风格确认的替代。
- image2 的具体版本需要可核验的工具记录。上轮工具未返回后端型号，现有记录只能证明使用了内置图像生成，不能证明精确模型版本。

### 5.3 下一次检查的通过条件

1. 390×844 与 1440×900 下，完整书体均在画布内，边缘有可见余量；文案不压场景。
2. 开书与合书全程没有可见纸片穿插；章节切换不会看到缺失背面的景片突然消失。
3. 正面能清楚分出近景植物、中景新人和远景庄园；斜侧面能看到纸层间距及支撑。
4. 森林绿与暖白形成明确对比；草地与人物轮廓在手机大小仍可辨认。无需放大才能看见的碎细装饰不能成为主要层次。
5. 近景植物不靠复制同一条花带堆数量；场地不被新人和花拱遮成一个背景色块。
6. 简洁版与 3D 版的主体、层次和颜色一致。
7. 以用户对完整第一幕的反馈确认美术方向，技术通过单独记录。

推荐顺序：构图与白纸结构样机 → 首幕整体美术稿 → 独立素材 → 实际搭建 → 开合和手机复验。先把一幕完整做稳，再把确定的规则应用到其余章节。
